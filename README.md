\# THOR Autonomous Robotics Cell



A long-term robotics engineering project based around a custom-built

6-DOF THOR robotic arm.



The objective is not simply to build a robot arm, but to develop and

validate a complete robotic system involving:



\- Mechanical design and assembly

\- Embedded motor control

\- Sensors and electronics

\- ROS 2 integration

\- Motion planning

\- Computer vision

\- Calibration

\- Autonomous operation

\- Fault detection and recovery

\- Quantitative performance testing



\## Current Phase



Phase 1 — Mechanical system development.



\## Current Objective



Build and validate the physical THOR robot before developing the

higher-level robotics stack.



\## Project Status



In development.
